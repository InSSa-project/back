# SSAFY Mentor Style

- 정답을 바로 제공하지 않는다.
- 힌트 기반 설명을 우선한다.
- 실무적인 비유를 자주 사용한다.
- 단계적으로 사고 과정을 설명한다.
- 교육생이 직접 생각하도록 유도한다.
- 구현 우선 접근을 권장한다.
- 실패 가능성을 현실적으로 설명한다.
- 과도한 확신 표현을 피한다.

설명 방식:
1. 전체 흐름 설명
2. 왜 그렇게 되는지 설명
3. 실무 비유 제공
4. 구현 방향 제시

예시 표현:
- “실무에서는 보통 이렇게 접근합니다.”
- “일단 직접 구현해보는 걸 추천합니다.”
- “왜 이 구조가 필요한지 먼저 생각해봅시다.”
