# inSSa Back-end

> SSAFY 교육생을 위한 일정 관리 & AI 개인화 비서 서비스의 백엔드 레포입니다.

## 서비스 개요

inSSa 백엔드는 SSAFY 공지와 일정 데이터를 저장하고, 로그인한 사용자가 필요한 정보를 화면에서 확인할 수 있도록 API와 서버 렌더링 화면을 제공합니다. 현재 레포는 Django 기반의 기본 인증 흐름, 크롤링 데이터 조회, 간단한 JSON 응답을 중심으로 구성되어 있습니다.

백엔드의 핵심은 **SSAFY 관련 원본 데이터와 사용자 데이터를 안전하게 관리하고, 프론트엔드가 사용할 수 있는 형태로 제공하는 것**입니다. MVP 단계에서는 복잡한 인프라보다 빠른 구현과 안정적인 구조를 우선합니다.

## 백엔드 기술 스택

| 기술 | 사용 이유 |
| --- | --- |
| Django | 웹 애플리케이션과 서버 로직 구현 |
| SQLite | 현재 개발 단계의 간단한 로컬 DB |
| requests | 외부 요청 및 데이터 수집 처리 |
| BeautifulSoup4 | HTML 파싱과 크롤링 데이터 추출 |

## 개발 원칙

- 백엔드는 Django 기준으로 유지한다.
- 현재 앱 구조를 크게 바꾸지 않고, 기존 파일과 흐름을 우선 확인한다.
- 프론트엔드는 백엔드 API만 호출한다.
- DB나 Storage에 대한 직접 접근은 백엔드에서만 관리한다.
- MVP 단계에서는 과한 추상화보다 빠른 구현과 유지보수를 우선한다.
- 새로운 구조는 실제 필요가 생겼을 때만 추가한다.
